gadgetry-most-foul
==========

A hard fork of [usb-gadget], focusing on providing a high performance I/O API for FunctionFS implementations.

It's primarily intended for use by the [smoo] and [gud-gadget] projects.

These downstream changes are almost entirely maintained by robots. If you're thinking of contributing, please consider going upstream rather than proposing changes here.
